How it works

YOURLS underneath, a SaaS dashboard on top.

Untouched

YOURLS core

Redirect logic, MySQL schema, click tracking, plugin API — includes/, stock.

Added

Leanks plugin

Hooks redirect_shorturl; checks password / expiry metadata before a click is logged.

Custom

Leanks dashboard

A separate front end in app/, talking to YOURLS' own admin-ajax.php.

YOURLS is plain PHP, MIT licensed, has no build step, and stores everything in a couple of MySQL tables — a good fit for cheap shared/cPanel hosting. Leanks keeps that core completely stock and adds a small plugin (user/plugins/leanks) plus an entirely custom front end (app/) on top, rather than patching YOURLS' own files. YOURLS itself stays upgradeable in place.

Password protection, expiration and click limits are enforced by hooking YOURLS' redirect_shorturl action: before a click is logged and redirected, Leanks checks a small metadata table and can intercept the request with a password prompt or an "expired" page. Everything else — the redirect itself, click counting, referrer/geo logging — is stock YOURLS.

The dashboard talks to YOURLS' existing admin-ajax.php for link create/edit/delete, reusing its built-in nonce-based CSRF protection and session auth, plus a handful of custom leanks_* actions the plugin registers for listing, stats, and CSV import.

Installation

Running in about five minutes.

PHP 8.1+ MySQL 5.7+ or MariaDB pdo_mysql extension Apache + mod_rewrite

  1. Create a database and database user

    On shared/cPanel hosting the setup wizard connects to an existing database — it usually can't create one itself. In cPanel: MySQL® Databases → create a database → create a user → Add User to Database with all privileges.

  2. Upload the repository to your web root

    Keep the folder structure intact, e.g. into public_html.

  3. Run the setup wizard

    Visit https://your-domain.com/setup/ and enter the database details and an admin username/password. This writes user/config.php, creates the tables, and activates the Leanks plugin automatically.

  4. Remove the setup folder

    Delete (or password-protect) /setup once installed — it can rewrite your database credentials and shouldn't stay reachable.

  5. Log in

    Go to https://your-domain.com/app/ with the admin account created in step 3.

Prefer to configure by hand? Copy user/config-sample.php to user/config.php, fill in your settings, then visit /admin/install.php (YOURLS' own installer) followed by /admin/plugins.php to activate the "Leanks" plugin.

FAQ

Common questions.

Is Leanks really free?

Yes. Leanks is open source under the MIT license, with no paid tier and no feature gates. You only pay for the PHP/MySQL hosting you run it on, which can be an ordinary shared host.

How is Leanks different from YOURLS?

Leanks is YOURLS underneath: the redirect engine, database schema, click tracking and plugin API stay stock. On top it adds a modern dashboard plus password-protected links, expiration, a UTM builder, tags, QR codes, analytics, CSV import and export, and one-click updates.

What hosting do I need?

PHP 8.1+, MySQL 5.7+ or MariaDB with the pdo_mysql extension, and Apache with mod_rewrite. Typical shared and cPanel hosting works. There is no Node build step and no Docker.

Where is my data stored?

In the MySQL database on your own server. Leanks is software you install, not a hosted service, so there is no account with us and nothing to sign up for.

Can I move my links in and out?

Yes. CSV import detects columns automatically and reports duplicates and errors per row. CSV export uses the same column names, so a file re-imports cleanly into another install. Clicks, creation dates and tags travel with it; passwords, expirations and UTM fields don't.

How do updates work?

The dashboard notices new releases on GitHub and applies them in place after verifying a checksum and taking an automatic backup. If anything fails partway, it rolls back from that backup.
